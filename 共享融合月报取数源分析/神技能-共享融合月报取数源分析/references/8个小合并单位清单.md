# 湖北电力 — 8个小合并单位清单

> ⚠️ **核心原则**：这 8 个小合并单位**不适用**76个单体表/大合并的账务取数公式体系。它们的正式报表中**没有账务取数**。
> **注意**：大合并（1002湖北电力）与小合并不同——**大合并有完整账务取数，公式体系和单体表一致**，详见[大合并单位说明](./大合并单位说明.md)。

## 公式体系特征

| 对比项 | 单体表（76家） | 小合并（8家） |
|--------|---------------|-------------|
| 资产负债月报表 | ✅ 有账务取数 | ❌ 零个账务取数 |
| 利润月报表 | ✅ 混合（历史+中间表+账务） | ❌ 零个账务取数 |
| 现金流量月报表 | ✅ 账务取数（现金流量分类） | ❌ 零个账务取数 |
| 成本情况月报表 | ✅ 账务取数（业务板块+功能范围） | ❌ 零个账务取数 |
| 资产负债表中间表(重分类) | 105个账务取数 | 105个账务取数（模板残留，非主用） |
| 总批注数 | ~18,569条 | ~15,358条 |

**小合并的公式只有两种：**

1. **取数公式 — 全部是「去年历史」引用**
   ```
   去年.12.资产负债月报表.(货币资金元_2,期末数_5)
   去年.利润月报表（三）.(主营业务收入_2,本年数_4)
   ```

2. **运算公式 — 表内汇总/计算**
   ```
   .(A,期末数) - .(A,上年同期数)
   利润月报表（三）.(营业收入_1,本月数_33)
   ```

## 数据来源路径

```
下级单体表单位的报表
    ↓ 汇总叠加
    ↓ 合并抵销
小合并正式报表（资产负债/利润/现金流/成本）
```

> 小合并不查SAP、不查科目维度汇总表，数据完全来自下属单体表的汇总。

**⚠️ 不要与大合并混淆！**

| 层级 | 数量 | 正式报表有账务取数？ |
|------|------|-------------------|
| **大合并 (1002)** | **1家** | **✅ 有（485+个），公式=单体表** |
| **小合并** | **8家** | **❌ 无** |
| 单体表 | 76家 | ✅ 有 |

> 小合并是唯一一个层级"没有账务取数"的。大合并和单体表的公式体系一致。

## 小合并单位的问题排查策略

当用户反馈小合并报表数据异常时：

1. **确认是否为运算/历史引用问题** — 直接读批注即可分析
2. **如果数值本身不对** → 追溯到对应的**下级单体表单位**，使用单体表公式体系进行分析
3. **检查合并抵销** — 重点看内部交易情况表、抵销分录是否完整
4. **中间表的账务取数批注** — 可作为辅助核对手段，但非主数据源
