# 共享融合月报取数源 - 公式体系说明

## 概述

共享融合系统中的快报，每个数据单元格都通过**批注（Comment）**记录了其计算/取数逻辑。
共有 **18,569 个批注**，分为两大类：**运算公式** 和 **取数公式**。

---

## 一、两种公式类型

### 1.1 运算公式（内部汇总）

**标识**：`运算公式1 :`

**含义**：根据本表或其他表上方格子的值进行加减乘除等运算得出。不是从外部取数。

**格式规律**：
```
.(行项目名_行次, 列字段_列次)  +  .(另一个行项目_行次, 列字段_列次)
```

**常见模式**：
| 计算目标 | 公式模式 | 示例 |
|---------|---------|------|
| 增减额 | 本期数 - 上年同期数 | `.(货币资金元_2,期末数_5) - .(货币资金元_2,上年同期数_6)` |
| 增减率 | 增减额 / ABS(上年同期数) | `.(增减额_7) / ABS(.(上年同期数_6))` |
| 小计/合计 | 多个明细项相加 | `.(A_3,本月数_4)+.(B_4,本月数_4)+.(C_5,本月数_4)` |
| 跨表汇总 | 引用其他表的合计 | `利润月报表（三）.(一、营业收入_1,合计-本月数_33)` |

**特点**：
- 数据来源于同一文件内的其他单元格
- 不涉及账务查询
- 通常用于：小计、合计、增减额、增减率、比率指标

---

### 1.2 取数公式（外部获取）

**标识**：`取数公式1 :`

**含义**：从外部数据源获取数值，分为三种来源：

#### 来源A：历史报表（往年数据）

**用途**：年初数、上年同期数

**格式**：
```
{期间前缀}.{表名称}.({行项目}_{行次}, {列字段}_{列次})
```

**示例**：
```
去年.12.资产负债月报表.(货币资金元_2,期末数_5)
去年.资产负债月报表.(货币资金元_2,期末数_5)
去年.现金流量月报表.(销售商品、提供劳务收到的现金_2,本期金额_3)
```

**期间前缀规则**：
- `去年.` → 上年度同期
- `去年.12.` → 上年末（用于年初数）

#### 来源B：中间表 / 其他报表

**用途**：本期期末数的部分来源

**格式**：
```
.{表名称}.({行项目}_{行次}, {列字段}_{列次})
```

**示例**：
```
.资产负债表中间表（单体-重分类）.(元_2,重分类后金额_6)
可再生能源补贴情况统计表.(风力发电项目_2,应收补贴期末余额_5)
利润月报表（三）.(一、营业收入_1,合计-本月数_33)
```

#### 来源C：账务取数 ⭐（核心重点）

**用途**：直接从财务账簿中按科目维度提取

**完整格式解析**：
```
账务取数：{财务组织}_{期间}__{账簿类型}_({科目条件})_{币种}__{取值字段}__{合并标志}
```

**各组成部分**：

| 组成部分 | 说明 | 示例 |
|---------|------|------|
| **财务组织** | 固定值 | `本财务组织` |
| **期间** | 年度+月份 | `本年_本月`、`本年_本年` |
| **账簿类型** | 会计账簿编号 | `01 中国大陆企业会计账簿` |
| **科目条件** | 科目代码或现金流量分类 | `(1002 银行存款)+(1001 库存现金)+(1012 其他货币资金)` 或 `(现金流量分类_...\销售商品...)` |
| **币种** | `本位币(人民币)` | 固定 |
| **取值字段** | 具体取哪个余额/发生额 | `期初借方余额`、`期末借方余额`、`年借方发生额`、`年贷方发生额`、`期末贷方余额` |
| **合并标志** | `合并数` | 固定 |

**科目条件的写法**：
- **单科目**：`(1002 银行存款)`
- **多科目合并**：`(1002 银行存款)+(1001 库存现金)+(1012 其他货币资金)`
- **现金流量分类**：`(现金流量分类_现金流量分类\\经营活动产生的现金流量\\经营活动现金流入\\销售商品、提供劳务收到的现金)`

**取值字段对照表**：

| 取值字段 | 对应科目维度汇总表字段 | 说明 |
|---------|---------------------|------|
| 期初借方余额 | 期初余额 | 期初借方 |
| 期末借方余额 | 期末余额 | 期末借方 |
| 期末贷方余额 | 期末余额 | 期末贷方 |
| 年借方发生额 | 年借方累计 | 本年累计借方 |
| 年贷方发生额 | 年贷方累计 | 本年累计贷方 |

> **⚠️ 注意**：账务取数时，需要根据科目代码到「科目维度汇总表」中进行匹配查询。
> 匹配条件通常为：科目代码 = 批注中的科目代码，可能还需要匹配功能范围、业务板块等辅助维度。

#### ⚠️ 高频问题：辅助维度条件导致取数为空（已实测验证！）

**典型案例 — 成本情况表本年累计数为空但本月数有值：**

- **现象**：本月数(E列)有值 ✅，本年累计数(F列)却为空 ❌
- **批注条件**（以水费为例）：
  ```
  _(660002 成本费用\水费)_(业务板块_业务板块\电热力\储能;功能范围_生产成本-基本)
  +(同上)(业务板块_业务板块\电热力\增量配电;功能范围_生产成本-基本)
  +(同上)(业务板块_业务板块\电热力\其他电热力;功能范围_生产成本-基本)
  ```
- **根因**：该单位实际的业务板块是 `风电`/`光伏`，不在模板预设的3个条件中
- **结果**：条件匹配不上 → 查出来为空

| 排查步骤 | 操作 | 目的 |
|---------|------|------|
| ① | 看批注中的 `(业务板块_XXX;功能范围_YYY)` 条件 | 了解模板要求匹配什么 |
| ② | 去科目维度汇总表对比实际业务板块/功能范围 | 确认是否匹配 |
| ③ | 如不匹配 → SAP检查凭证的业务板块维护 | 确认源头数据 |

**整改方向**：
- **SAP端**：凭证的业务板块/功能范围维护是否正确
- **报表模板端**：模板条件写死不适用 → 联系管理员调整模板

## 三、完整数据链路

```
┌──────────────┐      推送       ┌────────────────────────┐     取数公式      ┌─────────────┐
│   SAP 系统    │ ───────────→  │  共享融合系统           │ ←───────────   │  报表单元格  │
│              │               │                        │                │             │
│ • 财务凭证    │  科目维度      │ • 科目维度汇总表(SAP推送) │  账务取数公式    │  D22=58万    │
│ • 现金流量分类 │  汇总数据      │ • (期初/发生额/期末余额) │  引用此表数据    │             │
└──────────────┘               └────────────────────────┘                └─────────────┘
```

**关键认知**：
- **SAP** 是源头：所有账务（凭证、现金流量分类）都在 SAP 中录入
- **科目维度汇总表** = SAP 推送到共享融合的数据快照/副本
- **报表批注中的「账务取数」** = 实际上是在读取这张由 SAP 推送来的科目维度汇总表

### 因此，整改路径要分清：

| 问题层级 | 问题表现 | 去哪里改 | 操作人 |
|---------|---------|---------|--------|
| **SAP层** | 凭证金额错、现金流分类选错、借贷方向反了 | 在 **SAP** 中调整凭证 | 财务/SAP操作员 |
| **推送层** | SAP已改但共享融合未刷新 | 在共享融合中**重新获取/同步**数据 | 系统管理员 |
| **报表层** | 中间表数据有误、运算公式引用错误 | 修改对应中间表或源报表格子 | 报表编制人 |

## 四、各报表的取数特征

### 资产负债月报表（669个批注）
- 年初数 → 取去年12月的资产负债表期末数
- 期末数 → 主要取「资产负债表中间表（单体-重分类）」的重分类后金额
- 增减额 = 期末数 - 年初数（运算公式）
- 增减率 = 增减额 / ABS(年初数)（运算公式）

### 利润月报表(总)（395个批注）
- 本月数、本年累计数、上年同期数 → 取自「利润月报表（三）」的合计行
- 属于二次汇总表

### 利润月报表(一/二/三)（1351+927+1413个批注）
- 最底层的利润明细表，按业务板块（核电、煤电、铝业、电力服务等）分列
- 运算公式为主，做各板块的加总

### 现金流量月报表（120个批注）
- 本期金额 → 全部是**账务取数**，基于现金流量分类
- 上年同期金额 → 取去年的现金流量表

### 成本情况月报表、技术经济指标表等
- 结构类似，包含大量运算公式和跨表引用

## 三、分析工作流

当需要追溯某个数据的取数来源时：

1. **定位单元格** → 确定在哪张报表、哪一行、哪一列
2. **读取批注** → 查看 cell.comment.text
3. **判断公式类型**：
   - 若以 `运算公式1:` 开头 → 追踪被引用的格子
   - 若以 `取数公式1:` 开头 → 分析取数来源
4. **若为账务取数** → 解析出科目条件，去科目维度汇总表中查找对应科目的实际值
5. **验证一致性** → 对比报表值与科目维度汇总表中的值是否一致
