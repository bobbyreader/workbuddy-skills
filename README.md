# 项目团队自研神技能包

发电项目组自研的四个神技能包，服务于GJDT集团DAP9版财务共享系统。

## 技能列表

| 技能名称 | 描述 |
|---------|------|
| **神技能-共享融合月报取数源分析** | 共享融合系统快报取数源分析，支持月报三级报表体系（单体表→小合并→大合并）的数据追溯，核心能力是解析Excel批注区分运算公式与取数公式 |
| **神技能-外部司库运维** | ERP资金支付问题诊断技能，覆盖银企对账、支付指令、资金计划、融资融合等资金支付全链路问题定位 |
| **神技能-税务共享运维** | 税务共享模块（进项/销项发票管理）运维诊断技能，含配置指南、操作流程、FAQ知识库 |
| **神技能-资金管理运维** | 资金管理模块专家级运维技能，覆盖收款认款、资金计划、银企对账、配比支付、票据管理、融和e链六大子模块 |

## 适用系统

- GJDT集团 DAP9版本 财务共享系统
- 共享融合系统
- 司库管理系统

## 使用方式

每个技能目录下包含完整的 `SKILL.md` 和 `references/` 知识库文件，导入WorkBuddy即可使用。
