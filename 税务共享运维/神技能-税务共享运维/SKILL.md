# 神技能-税务共享运维

## 描述
GJDT集团DAP9版本财务共享系统 — 税务共享模块（进项发票管理 + 销项发票管理）的运维诊断与操作指导技能。当用户遇到税务共享模块的配置问题、操作疑问、故障排查时，使用此技能快速定位解决方案。

## 适用场景
- 税务共享模块配置咨询（进项/销项参数、调度任务、采集范围等）
- 进项发票管理操作指导（采集、查验、收管、勾选认证、账票核对）
- 销项发票管理操作指导（开具、红冲、拆分、台账、账票核对）
- 百望云系统配置（权限、签名密码、全电通道、全电账号）
- 常见问题排查（FAQ 10个高频问题）
- 多单位共用税号场景处理
- 数电票（全电发票）相关操作
- 1455项目单位SAP凭证集成问题

## 不适用场景
- 非税务共享模块的问题（请使用 erp-payment-troubleshooter 技能）
- 资金支付、银企对账等非税务相关问题

## 运维诊断工作流

当用户提出税务共享问题时，按以下步骤进行：

### Step 1: 问题分类
根据用户描述，判断属于以下哪类：
| 分类 | 关键特征 |
|------|---------|
| **进项配置** | 参数设置、调度任务、采集范围、百望配置 |
| **销项配置** | 开票参数、终端配置、商品信息、全电账号 |
| **进项操作** | 采集不到票、勾选失败、签名卡住、收管异常 |
| **销项操作** | 开票失败、红冲失败、拆分、台账问题 |
| **账票核对** | 进项/销项税额差异、SAP凭证穿透 |
| **多单位共用** | 清分规则、引用授权、看不到发票 |

### Step 2: 快速定位
在知识库中用关键词搜索（Ctrl+F / 搜索工具），优先匹配：
1. **错误信息关键词**：如"统计签名中"、"未登录"、"连接断开"
2. **功能名称**：如"发票勾选"、"红冲"、"开具"
3. **参数名**：如"JXS_KMID"、"OPEN_EXAMINE_STATE"
4. **业务场景**：如"自动入池"、"全电通道"

### Step 3: 给出解决方案
按照以下格式输出：

```
🔍 **问题定位**：[一句话说明问题根因]

📋 **解决方案**：
1. [具体步骤1]
2. [具体步骤2]
...

⚠️ **注意事项**：
- [关键提醒]

📖 **参考章节**：知识库 X.X.X 节
```

### Step 4: 必要时追问
如果问题描述模糊，需确认：
- 操作单位层级（9999 / 合并层 / 底层单位）？
- 发票类型（专票/普票/电票/数电票）？
- 错误发生的具体界面和提示信息？
- 是否为1455项目单位（涉及SAP集成）？

## 关键参数速查

### 必背参数
| 参数名 | 参考值 | 用途 |
|--------|--------|------|
| JXS_KMID | 131261 | 进项账票核对科目ID |
| FPCJ_METHOD | 8 | 发票取数通道=发票中心 |
| ENTER_INV_POOL_OPEN | 1 | 企业发票池开关=开启 |
| IS_OPEN_CHECK | 1 | 查验开关=开启 |
| OPEN_EXAMINE_STATE | 1 | 取消复核(0=开启) |
| PAPER_DRAW_NULLIFU_SUPPLIER | 6 | 纸票开票通道=百旺 |
| ELEC_DRAW_NULLIFU_SUPPLIER | 6 | 电票开票通道=百旺 |
| ALLELEC_DRAW_NULLIFU_SUPPLIER | 6 | 数电票开票通道=百旺 |
