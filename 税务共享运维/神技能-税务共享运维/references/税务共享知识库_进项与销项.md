## 一、系统概览

### 1.1 应用架构

税务共享应用蓝图分三层：

| 层级 | 内容 | 说明 |
|------|------|------|
| **标准管控层** | 基础体系 + 基础数据维护 | 参数配置、组织映射、商品信息等 |
| **业务处理层** | 进销项发票全生命周期 + 各税种纳税管理 + 发票开具/红冲/作废 | 核心业务操作 |
| **分析决策层** | 统计分析 + 风险防控 + 税务筹划 | 账票核对、敏感性分析等 |

### 1.2 进项 vs 销项 功能对照

| 维度 | 进项发票管理 | 销项发票管理 |
|------|-------------|-------------|
| **核心业务** | 发票采集 → 查验 → 收管 → 勾选认证 → 统计签名 | 应收回写 → 开票复核 → 发票开具 → 红冲/作废 |
| **外部对接** | 百望云进项系统 / 电子税务局（全电通道） | 百望云销项系统 / 集团邮箱系统 |
| **内部关联** | 报账平台（应付结算单、费用报销单、差旅费报销单） | 报账平台（应收确认单） |
| **账票核对** | 进项账票核对（凭证进项税额 vs 发票税额） | 销项账票核对（凭证销项税额 vs 发票税额） |
| **台账查询** | 进项发票台账、敏感性分析、备注栏校验、未认证查询 | 销项发票台账、领用登记、数据导入导出 |

#### 2.1.8 📋 发票采集范围设置（⭐ 进项最关键的配置）

**关键词**：`发票采集范围` `纳税人识别号` `清分规则` `引用授权` `自动入池` `多单位共用税号`

**菜单路径**：登录底层单位 → 【智慧应用中心】→【税务共享】→【标准管控】→【基础管理\发票基础设置】→【发票采集范围设置】

**前置条件**：无  
**后置功能**：发票采集、发票勾选

**核心概念：多单位共用税号**

```
场景示例：
A公司有税号X，B公司和C公司也有自己的税号，
但B、C仍使用A的税号X来收票。
→ A是税号X的"归属单位"，B、C是税号X的"使用单位"
发票按税号被采集至归属单位A，由A设置B、C为使用单位
```

**两种分配方式对比**：

| 方式 | 适用场景 | 操作位置 | 说明 |
|------|---------|---------|------|
| **发票清分** | 票面内容不同（备注栏/电话/银行账号不同） | 归属单位设置清分规则 | 采集时按票面自动清分至最终使用单位 |
| **引用授权** | 票面内容完全相同，无法区分 | 归属单位设置引用授权 | 允许其他单位使用该税号下的发票，使用时标记 |

**配置步骤**：

**（一）基本配置**：
1. 进入【发票采集范围设置】界面，展示"进项"和"销项"两部分
2. 在"进项"部分配置：
   - **纳税人名称**：按客户收集资料填写
   - **纳税人识别号**：按客户收集资料填写
   - **所属省份**：按实际填写
   - **接口提供方**：选"智税云"
   - **自动入池方式**：
     - "入账后自动加入"：发票相关凭证入账后自动加入勾选任务池提交税局
     - "无"：无自动操作，需人为提交勾选
3. 勾选 **"开启采集"** 和 **"开启认证"**

**（二）清分规则设置**（登录二级管理范围单位）：
1. 左侧组织树选中"税号所属单位"

### 4.2 发票认证

---

#### 4.2.1 ✅ 发票认证（勾选/撤销勾选/统计签名）

**关键词**：`发票勾选` `撤销勾选` `统计签名` `认证任务池` `自动入池` `税款所属期`

**菜单路径**：登录底层单位 → 【智慧应用中心】→【业务处理】→【进项发票管理\发票认证】→ 【发票勾选】/【撤销勾选】/【认证统计和签名】

**（一）发票勾选（含自动勾选）**

**入口**：【发票勾选】

**操作流程**：

**Step 1 — 选择勾选类型**：
- 抵扣勾选
- 不抵扣勾选

**Step 2 — 选择归属单位**：
- 默认=当前登录单位
- 多单位共用税号时可选择：当前单位/清分单位/授权单位

**Step 3 — 添加待勾选发票到任务池**：

**方式一：手工入池**
- 扫描枪扫描二维码
- 输入发票号码手工添加
- 检索添加（查到归属单位=A且使用单位=D的未勾选发票）
- 扫描仪批量添加

**方式二：自动入池**（满足所有以下条件才自动入池）：
1. ✅ 与已完成的凭证有关联（通过费用报销单/差旅费/应付结算单引用，单据流转至凭证已完成）
2. ✅ 凭证制证日期处于**企业当前税款所属期内**
3. ✅ 发票状态为**未勾选**
4. ✅ 发票类型为：增值税专用发票/电子专用发票/数电专票/通行费电子普通发票（不含不征税）/机动车销售统一发票
5. ❌ 小规模纳税人不适用自动勾选

> 💡 **提示**：非本单位使用的发票，建议先收管再提交勾选，避免任务池/清单没有查询权限。

**Step 4 — 确认勾选**：
- 选择待勾选发票 → 【提交勾选】→ 加入认证任务池
- 自动入池的无需手工提交
- 间隔一段时间后查看结果
- 【已勾选清单】/【已撤销清单】查看

**（二）撤销勾选**

**入口**：【撤销勾选】

**操作**：
1. 选择撤销单位（同勾选时的单位范围）
2. 添加待撤销发票（四种方式同勾选）
3. 【撤销勾选】→ 后台自动处理
4. 查看结果 → 撤销成功的恢复未勾选状态，可再次勾选

**（三）认证统计与签名**

**入口**：【认证统计与签名】
> ⚠️ **仅"归属单位"（采集单位）可操作**

**操作流程**：
1. **申请统计**：查看当期勾选成功的抵扣/不抵扣发票统计 → 【申请统计】
   > ⚠️ 申请统计后当前税期锁定，不能再勾选！需撤销统计才能重新勾选
2. **确认统计**：审核统计信息 → 有误则【撤销统计】；无误继续
3. **确认签名**：申请签名界面 → 【确认签名】
4. **完成**：显示"认证签名已完成，可进行本月增值税申报工作"
5. 如需重新勾选：逐步【撤销签名】→【撤销统计】后再次勾选

#### 5.3.1 场景一：应收确认单发起开票（推荐✅）

**完整流程**：形成待开数据 → 确认终端及发票数据 → 发票复核 → 发票开具 → 回写应收单

**（一）形成待开数据**

在报账平台操作（详见《应收管理操作手册》）：
1. 路径：【报账平台】→【应收报账】→【应收业务处理】→【应收确认单】
2. 基本信息：
   - "开具方式"选"**线上开具**"
   - 选"发票类型"
3. 详情信息-应收明细：
   - 【新增】→ 必填"**业务小类**"→ 选"**商品类型**"→ 自动带出商品名称和税收分类编码
   - 填"含税金额/税率/数量" → 其他字段自动计算
4. 单据向后传递 → 到达"**税务专责岗**"时，待开信息传递至税务共享

**（二）税务共享确认**

**（三）确认终端及发票数据**

1. 勾选一张发票 → 【下一步】
2. "确认发票终端/开票员信息"界面 → 终端和开票人自动带出（可手工调整终端）
3. 仅可查到能开此票种且**使用单位为本单位**的终端
4. 【下一步】

**（四）确认发票数据**

1. 确认发票信息 → 【提交复核】（如取消复核功能则跳过此步）
2. **发票复核**（可选）：复核人进入【发票复核】→【审核通过】/【审核不通过】

**（五）发票开具**

1. 【确认开具】→ 完成
2. 已开发票明细**自动回写**至报账平台应收确认单"开票明细"子表

**⚠️ 单据回退逻辑特别重要**：

| 条件 | 能否回退 | 说明 |
|------|---------|------|
| 未形成税务共享待开数据 | ✅ 直接回退 | — |
| 已形成待开数据，完全未开票 | ✅ 直接回退 | 回退至税务专责岗之前→待开数据自动删除 |
| 已形成待开数据，**已实际开票**（全部或部分），回退至**税务专责岗之后** | ✅ 可直接回退 | 待开数据不变 |
| 已形成待开数据，**已实际开票**，回退至**税务专责岗及之前** | ❌ **必须先手工作废/红冲**已开发票 | 未开的待开数据自动删除 |

## 六、常见问题排查（FAQ）

### Q1: 发票勾选了但没有认证成功？

**可能原因及排查**：
1. **百望权限未开启** → 检查百望"取数""认证"权限是否开启（2.3.1节）
2. **签名密码不一致** → 百望和税局密码不同导致"统计签名中"卡死（2.3.2节）
3. **全电通道断开** → 检查数电配置连接状态（2.3.3节）
4. **调度任务未运行** → 检查"认证任务池调度"和"统计签名请求调度"任务是否启动（2.1.2节）
5. **软证书未开通** → 确认进项软证书是否已完成

### Q2: 进项发票采集不到数据？

**排查顺序**：
1. 检查**发票采集范围设置**是否正确配置（纳税人名称/识别号/省份/开启采集）（2.1.8节）
2. 检查**智税云通道参数**是否配置正确（ZSY_COLLECT_HOST_URL等）（2.1.1节）
3. 检查**增值税进项发票采集任务**调度是否正常运行（2.1.2节）
4. 检查百望**取数权限**是否开启（2.3.1节）
5. 确认税局端是否有发票数据

### Q3: 销项发票开具失败？

**常见原因及解决**：

| 失败原因 | 解决方案 |
|---------|---------|
| 百望连接不通 | 检查BWGF_OPERATOR_URL等接口地址和网络 |
| 全电通道断开 | 重新做开票员认证登录（3.3.1节） |
| 开票员线下登了电子税务局 | ⚠️ 这是禁忌！停止线下登录，重新连接通道 |
| 终端信息不对 | 检查开票网点/终端/票种核定是否匹配（3.1.7节） |
| 商品/销方信息缺失 | 检查商品信息维护（3.1.6节）和销方信息（3.1.8节） |
| 超过开票限额 | 使用发票拆分功能（5.4节） |

### Q4: 统计签名一直处于"统计签名中"？

**根因**：百望签名密码 ≠ 税局签名密码

**解决**：
1. 确认客户是否在税局端改过密码
2. 由远光本地同事在百望端重新设置为一致的密码（建议88888888）
3. 如已切全电平台则不受此影响（无需签名密码）

### Q5: 多单位共用税号，某单位看不到发票？

**排查步骤**：
1. 确认税号**归属单位**是否配置了**清分规则**或**引用授权**（2.1.8节）
2. 确认**使用单位**的基础组织中是否维护了正确的**纳税范围**（2.1.6节）
3. 确认发票是否已被清分/授权
4. 使用**进项发票台账**（而非发票采集）查看"使用单位"为当前单位的发票

### Q6: 自动勾选没有生效？

**检查自动入池条件**（4.2.1节）：
1. ✅ 发票是否与**已完成凭证**关联？
2. ✅ 凭证**制证日期**是否在当前**税款所属期**内？
3. ✅ 发票类型是否符合（专票/电子专票/数电专票/通行费电票/机动车票）？
4. ✅ 是否为**小规模纳税人**？（不支持自动勾选）
5. ✅ **发票采集范围设置**中"自动入池方式"是否为"入账后自动加入"？
6. ✅ **发票勾选自动入池**调度任务是否正常运行？（每1小时）

### Q7: 应收确认单无法回退？

**检查回退逻辑**（5.3.1节）：
1. 是否已**实际开票**？已开票且需回退到税务专责岗及之前的 → **必须先手工作废/红冲**
2. 是否形成了**税务共享待开数据**？已形成且回退到税务专责岗之前 → 待开数据会自动删除

### Q8: 销项账票核对找不到数据？

**排查**：
1. **销项账票核对设置**中是否排除了相关税收分类编码（3.1.9节）
2. **销项账票核对参数**（KMID-SRJE-J/D等）是否正确配置（3.1.1节）
3. 发票是否已**采集入库**
4. 凭证是否已**入账完成**

### Q9: 数电票开票前每天都要做什么？

1. 开票员登录**百望云** → 【全电发票】→ **重新连接通道**（验证码或刷脸）
2. 确认连接状态为"已登录"
3. ⚠️ **切勿**同时用该账号线下登录电子税务局

### Q10: 1455单位如何查看SAP凭证？

**条件**：
1. 当前用户已在**4A系统完成认证**
2. 在**进项/销项账票核对**界面
3. 点击凭证分录区域的**凭证编号**
4. 即可穿透打开SAP系统的凭证
