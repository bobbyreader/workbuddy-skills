### 1.2 关键配置要点

#### 资金结算参数设置（9999）
- **推收款单参数**: 启用后可设置推单用户、手工补充摘要、推单日期
- **按勾选记录分开推收款单**: 默认不开启；开启后多条记录推单时提示是否分开
- **按勾选记录分开推扣款确认单**: 默认不开启；银行扣款同理

#### 资金支付系统参数设置
- `PS_GET_LOANSIGN_DATA` 值改为1: 解决单据关联流水数据显示空值
- `PSCOLLECTIONSETUSERROLE` 值改为1: 开启收款转交功能显示

#### 非电费收入参数设置（批量分拣规则）
- **用途**: 当某一收款账号被多个单位共用时，设置该账号的收款明细可由其他单位分拣
- **配置要素**: 收款单位名称 + 收款账号 + 归属单位（可多选）
- **注意**: 若账号仅被一家使用则无需配置

#### 认款规则设置
- **收支标志**: 收款认款选【收入】，银行扣款选【支出】
- **匹配应收**: 默认为【否】，国家电投项目**不具备上线条件，请勿配置**
- **默认标记制证**: 仅自动分拣的业务类型可设置为【是】
- **推单方**: 默认【收款单位】，可改为归属单位

#### 业务权限设置
- **权限类型-业务功能**: 设定角色/用户可见的功能菜单
- **权限类型-业务处理**: 设定角色/用户可处理的认款业务类型

### 1.3 用户操作要点

#### 收款认款推单流程
```
获取到账数据 → 待处理(到账分拣) → 自动分拣/手工分拣 → 已分拣 → 推收款单
```
- **获取到账数据**: 选择日期和银行账户获取交易流水
- **到账分拣**: 支持自动分拣（按预设规则）和手工分拣（人工选择认款类型）
- **标记制证**: 延期推单或已线下制证的流水可标记
- **推收款单**: 已分拣状态下的记录推送到待办

#### 银行扣款推单流程
```
获取到账数据 → 扣款分拣(自动/手工) → 推扣款确认单
```
- 支持【转交处理】【标记制证】【修改摘要】【标记主动付款】

### 2.2 控制方案核心逻辑

#### 按明细控制
- 控制方式: 当期控制 / 累计控制
- 无资金计划参数: 不允许发生 或 允许发生
- 提醒/控制百分比: 如80%提醒，输入80.00

#### 按总额控制
- 按科目总额控制: 单个科目可超但总额不可超
- 按维度总额控制: 所有科目合计总额控制，执行数按明细回写

### 2.3 用户操作要点

#### 编制流程
```
启动编制阶段 → 编审导航填报 → 提交审批 → 上级汇总 → 发布版本启动 → 数据发布
```

#### 调整流程
```
启动调整阶段 → 调整申请(调增调减) / 内部调剂(科目间) → 审批 → 重新发布
```

#### 特别注意事项
- 启动调整阶段后**不允许切回编制阶段**
- 内部调剂只能在**同类科目性质间**调剂（收入→收入或支出→支出）
- 调出方填负数，调入方填正数，合计必须为0

## 三、对账管理（用户操作手册）

### 3.1 功能场景清单

| 序号 | 功能场景 | 说明 |
|------|---------|------|
| 1 | 首次对账月初始化 | 上线前一次性操作；新增账户需操作 |
| 2 | 未对账明细初始化 | 首月对账导入历史未达账项 |
| 3 | 未授权账户收支余导入 | 未司库授权账户的手工导入 |
| 4 | 银企对账 | 核心功能：自动对账+手工对账+生成余额调节表 |
| 5 | 余额调节表查询 | 查询已保存的余额调节表 |
| 6 | 余额调节表汇总查询 | 统计已完成/未完成对账账户数量 |
| 7 | 单位账户收支余查询 | 三维度查看：单位/账户/交易流水 |
| 8 | 直连账户采集流水检查 | 检查计算余额≠期末余额的数据 |

### 3.2 银企对账关键步骤
```
选择账户+期间 → 自动对账 → 手工对账(补充) → 取消/无需对账/内部勾对 → 生成余额调节表
```
- **前提**: 调节后期末余额相等才能保存
- **内部勾对**: 处理调整期凭证，方向一致金额相反

### 3.3 文件命名规范
- 未对账明细初始化: `YYYYMMDD至YYYYMMDD`
- 未授权账户导入: `YYYYMMDD_YYYYMMDD`

## 四、资金支付（用户操作手册）

### 4.1 功能场景清单（4项）

| 场景 | 说明 |
|------|------|
| 资金配比支付 | 选择付款账户/结算方式/合并拆分等操作 |
| 转账签名审批 | 三岗签名审批 |
| 转账支付指令 | 电子支付(司库)或手工标记 |
| 付款记账 | 支付完成后制证处理 |

### 4.2 配比支付核心操作

#### 操作按钮清单
| 按钮 | 功能 | 注意事项 |
|------|------|---------|
| 新增 | 拆分支付 | - |
| 合并处理 | 多条合并支付 | 先设置合并规则 |
| 修改付款账户 | 批量修改付款账号 | - |
| 调整付款月份 | 跨月单据调整 | 用于资金计划跨月 |
| 退回-终止支付 | 永久终止 | **不可逆** |
| 退回-修改信息 | 收款方信息有误 | 推出"收款方信息调整单"重新入池 |

#### 结算方式限制
- 票据支付仅支持**商业承兑汇票/银行承兑汇票/财务公司承兑汇票**（除电子债权凭证）
- 融和e链仅支持**应付电子债权凭证**

### 4.3 签名审批界面功能
- 查看: 业务单据/预览凭证/电子影像/同组支付/审批轨迹
- 操作: 退回/撤回/导出

### 4.4 支付指令页签说明
| 页签 | 说明 | 可执行操作 |
|------|------|----------|
| 未发送 | 待发送指令 | 电子支付/手工支付 |
| 已发送 | 已发司库 | 检查支付状态 |
| 支付失败 | 司库/银行失败 | 重新支付/手工支付/退回 |
| 支付成功 | 完成 | 仅查询 |

#### 支付失败处理策略
- 弱校验类错误（大额预警/重复预警/对私预警）→ **重新支付**
- 其他错误（收款方信息错/余额不足）→ **手工支付** 或 **退回重做**

### 4.5 付款记账
- 本级支付制证 → 付款记账推出凭证
- **标记制证**: 无需制证时可标记
- 凭证状态: 未生成编号可作废，已生成编号只能冲销

## 五、票据管理（用户操作手册）

### 5.1 功能场景（6大场景）

| 场景 | 流程 | 关键路径 |
|------|------|---------|
| 票据签发(开立) | 配比支付→签名审批→指令(电子支付) | 【票据管理】-【应付票据管理】 |
| 票据背书(转让) | 应收票据配比→背书审批→背书指令 | 【票据管理】-【应收票据管理】 |
| 票据兑付 | 总账特殊付款单 | 小类选"支付应付账款_电子债权凭证" |
| 票据签收 | 获取电票→核对→签收→收取单→审批→指令 | 【收取签收确认】 |
| 票据托收 | 收款认款管理分拣→总账特殊收款单 | 认款类型="推总账特殊收款单" |
| 票据贴现 | 贴现申请→贴现单→审批→指令 | 【票据管理】-【贴现申请】 |

### 5.2 票据 vs 融和e链 区别
| 维度 | 票据管理 | 融和e链 |
|------|---------|--------|
| 凭证类型 | 商业/银行/财务公司承兑汇票 | 电子债权凭证 |
| 结算方式 | 除电子债权凭证外 | 仅电子债权凭证 |
| 对接系统 | 司库系统 | 云链(融和e链)平台 |
| 签发失败处理 | 退回 | 清空附件重新支付 |
| 贴现场景 | 支持司库直连+非直连 | 先云链贴现后报销报账接收 |

### 5.3 非司库直连场景
- **票据签收**: 通过收款认款管理界面，摘要【票据收取】，分拣后下推收款单
- **票据托收**: 收款认款管理，认款类型"推总账特殊收款单"，下推总账特殊收款单
- **票据贴现**: 先在司库完成贴现，后返回报账平台通过收款认款管理处理

## 六、融和e链（用户操作手册）

### 6.1 功能场景（6大场景）

| 场景 | 流程 | 特殊点 |
|------|------|-------|
| 账单签发 | 配比支付→审批→电子支付/标记开票 | 支持线下标记开票 |
| 账单转让 | 应收电子债权凭证配比→审批→电子支付/标记开票 | 仅线上票据可转让 |
| 账单兑付 | 总账特殊付款单 | 与票据兑付操作相同 |
| 账单签收 | 收款认款管理 | 摘要【接收融和e链账单】 |
| 账单托收 | 收款认款管理→总账特殊收款单 | 与票据托收相同 |
| 账单贴现 | 先云链贴现→返回报账平台 | 必须先在云链完成 |

### 6.2 融和e链特别注意
- **附件问题**: 签发/转让失败若包含invoiceList和contractList错误 → 使用【清空附件重新支付】
- **标记开票**: 线下已签发的账单可通过【标记开票】直接完成

## 七、常见故障排查速查表

### 7.1 配置类问题

| 问题现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 推收款单按钮灰显 | 产品授权码未导入 | 导入产品授权码_2182971 |
| 单据关联流水数据空值 | PS_GET_LOANSIGN_DATA未设值 | 支付参数设置该值改为1 |
| 收款转交功能不显示 | PSCOLLECTIONSETUSERROLE未开启 | 值改为1 |
| 认款规则设置保存失败 | 匹配应收默认为是 | 改为否（国家电投不支持此功能） |
| 找不到资金计划菜单 | 配置平台未引用标准菜单 | 菜单管理引用标准菜单 |
| 资金计划发布校验不通过 | 格式设置维度>科目维度对应 | 检查并调整维度设置 |

### 7.2 运维类问题

| 问题现象 | 可能原因 | 解决方案 |
|---------|---------|---------|
| 对账双方余额不平 | 存在未达账项未处理 | 补充手工对账或无需对账 |
| 无法设置首次对账月 | 已生成余额调节表 | 该账户不能再初始化 |
| 无法导入未达账 | 未设置对账初始月 | 先完成首次对账月初始化 |
| 支付失败-弱校验 | 大额/重复/对私预警 | 点击重新支付 |
| 支付失败-其他原因 | 收款方信息错/余额不足 | 手工支付 或 退回重做 |
| 融和e链签发附件报错 | invoiceList/contractList | 清空附件重新支付 |
| 资金计划调整不允许启动 | 存在未完成编制表单 | 确保所有表单编制完成 |
| 内部调剂稽核不通过 | 跨科目性质调剂 | 仅允许同类科目间调剂 |
| 采集流水检查"交易有误" | 计算余额≠期末余额 | 系统自动补采或手工补采 |

### 7.3 数据类问题

| 问题现象 | 解决方案 |
|---------|---------|
| 升级9版本后数据检查 | 历史数据会迁移，仅需检查完整性和导入当月数据 |

### 9.2 入池配比参数-支付申请衔接（L1）

#### 菜单路径
【应用中心】-【资金管理】-【资金日排程参数设置】-【入池配比参数】→「支付申请衔接」页签

#### 配置步骤
1. 选择业务类型: **其他应付项**
2. 点击【新增】
3. 输入金额值（默认0.00）
4. 支付处理模式: **本级简易支付**
5. 支付申请单据类型: **升级-资金支付单**
6. 支付申请流程: **1455资金支付申请（bpm）新**

#### 前置条件
- 需先配置业务单据《【国电投】资金支付单-配比池后台支付单》
- 需先配置【国电投】转账支付财务单及对应流程

> ⚠️ **按底层单位逐一配置**，上线时每个底层单位都需要操作此项

### 9.3 入池配比参数-财务审批衔接（L2）

#### 菜单路径
同上 → 切换至 **「财务审批衔接」页签**

#### 配置对照表

| 支付方式 | 财务审批单据类型 | 财务审批流程 |
|---------|-----------------|-------------|

| 票据背书 | 【国电投】应收票据支付财务单 | 1455应收票据支付财务单（BPM） |
| 现金支付 | 【国电投】转账支付财务单 | 1455资金支付转账支付财务单（BPM） |
| **应付票据** | **【国电投】应付票据支付财务单** | **1455应付票据支付财务单（BPM）** |
| 网银支付 | 【国电投】转账支付财务单 | 1455资金支付转账支付财务单（BPM） |

> ⚠️ **按底层单位逐一配置**；票据类详见票据管理部分单独配置

### 9.4 支付流程参数-支付环节参数设置（L3）

#### 菜单路径
【智慧应用中心】-【资金管理】-【资金日排程参数设置】-【支付流程参数】→「支付环节参数设置」页签

#### 配置要点
- 流程选择: **【升级-标准】一般转账实体流程**
- 类型分两类:
  - **整体属性**: 流程级别参数
  - **环节属性**: 各环节参数
- **是否签名岗**: 出纳/资金审核/资金复核三岗设为"是"
- **是否支付**: 操作"转账支付指令"的环节设为"是"

#### 参考配置结果

| 环节 | 是否签名岗 | 是否支付 | 说明 |
|------|-----------|---------|------|
| 资金初审 | 是 | 否 | 第一岗签名 |
| 资金复审 | 是 | 否 | 第二岗签名 |
| 出纳 | 是 | **是** | 第三岗签名+发送指令 |

> ⚠️ 如果和集团签名流程一致，**无需配置此项**

### 9.5 财务审批与实体衔接参数（L4）⭐ 关键

#### 菜单路径
【智慧应用中心】-【资金管理】-【资金日排程参数设置】→「财务审批与实体衔接参数」页签

#### 核心逻辑
将前端业务发起的财务审批单 → 衔接到 → 后端共享中心的签名审批实体流程

#### 配置字段说明

| 字段 | 说明 | 示例值 |
|------|------|-------|
| 源单据类型 | 前端提交的财务审批单据 | 【国电投】转账支付财务单 |
| 源流程 | 财审审批的BPM流程 | 1455资金支付转账支付财务单（BPM） |
| 源单位 | 业务发起的底层单位 | XXX公司 |
| 目标流程 | 后端的签名审批实体流程 | 1455一般转账实体流程（BPM） |
| **目标单位** | **签名审批执行单位** | **⭐ 见下方说明** |

#### ⚠️ 目标单位选择规则（极重要）
- **共享模式**: 选择**共享服务中心单位**（如：国电投（苏州）共享服务有限公司）
- **非共享模式**: 选择和源单位一致的业务发起底层单位

#### 需要配置的衔接关系清单

| 源单据类型（财务审批单） | 目标流程 |
|------------------------|---------|
| 【国电投】转账支付财务单 | 1455一般转账实体流程（BPM） |
| 【国电投】应付票据支付财务单 | 1455一般转账实体流程（BPM） |
| 【国电投】应收票据支付财务单 | 1455一般转账实体流程（BPM） |
| 应收票据收取相关 | 对应收款流程 |
| 电票贴现相关 | 对应贴现流程 |
| 薪酬相关 | 对应薪酬流程 |

> 💡 **湖北移管共享案例**: 目标单位选【国电投（苏州）共享服务有限公司】
